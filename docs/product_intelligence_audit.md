# LivePortfolio — Product Intelligence Audit

## 1. Executive summary

**LivePortfolio** is a web app that turns a user's CV, pasted profile text, or GitHub profile into a personal portfolio website, then lets the user edit it, preview it in multiple templates, and publish it on a LivePortfolio URL after payment.

The current product is built around a **free private build flow** and a **paid publishing flow**:

- **Free** users can create an account, import data, generate a portfolio, edit it, and preview it privately.
- **Basic** users can publish the portfolio live on a LivePortfolio URL.
- **Pro** users get additional templates, visitor analytics, QR code sharing, and weekly AI career score.

There are **two onboarding systems** in the repository:
- an **older monolithic `/create` wizard** that is still present and appears to be the default unless a flag is enabled;
- a **new account-first onboarding flow** under `/create/account` → `/create/import` → `/create/review` → `/create/address` → `/create/generate`, which is feature-flagged and “dark” by default.

The strongest implemented differentiators are:

- **CV/document import**
- **AI-written portfolio copy**
- **private preview before payment**
- **subdomain/slug-based publishing**
- **template switching**
- **Pro analytics**
- **Pro weekly AI score**

Some marketed or schema-level ideas are **not fully implemented or not live**, notably:

- **custom domains** are not available yet
- some **Pro “coming soon” features** are explicitly not built
- some onboarding/import capabilities are **feature-flagged**
- there are **legacy and transitional systems** in the codebase

This repository is well-suited for **content automation and product demos**, because it includes:
- stable routes,
- reusable templates,
- browser-test tooling,
- analytics and event instrumentation,
- and enough deterministic UI to support repeatable walkthroughs.

## 2. Product overview

### What LivePortfolio does

LivePortfolio creates a professional portfolio website from a user's career information, then hosts it on a public URL once the user pays to publish.

Evidence:
- landing page copy in `app/page.tsx`
- generation endpoint in `app/api/generate/route.ts`
- public portfolio rendering in `app/portfolio/[slug]/page.tsx`
- plan definitions in `lib/plans.ts`

### Primary problem it solves

It reduces the effort required to create a polished personal portfolio website, especially for professionals who:
- do not want to design a site from scratch,
- do not want to write their own portfolio copy,
- and need a shareable professional web presence quickly.

Evidence:
- landing page FAQ and positioning in `app/page.tsx`
- AI generation flow in `app/api/generate/route.ts`

### Who it is designed for

The codebase explicitly targets professionals and job seekers, especially in tech-related roles.

Evidence:
- audience schema in `app/page.tsx`
- role-specific templates in `components/templates/`
- template IDs in `lib/plans.ts`

Supported role/template categories include:
- developer
- designer
- data scientist
- product manager
- finance
- graduate
- cybersecurity

There is also broader landing-page language for:
- developers
- designers
- freelancers
- career switchers
- job seekers

### Core value proposition

**Build and preview for free, publish when ready.**  
The product combines:
- import from existing career materials,
- AI-written storytelling,
- portfolio templates,
- hosted publishing,
- and optional Pro growth features.

Evidence:
- plan features in `lib/plans.ts`
- pricing UI in `components/PricingSection.tsx`
- upgrade flow in `components/UpgradeModal.tsx`

### Complete user journey from signup to publishing

#### Current implemented journey

1. User lands on marketing site at `/`
   - `app/page.tsx`

2. User starts creation flow
   - either legacy `/create`
   - or new `/create/account` flow if enabled
   - `middleware.ts`
   - `lib/onboarding/flag.ts`

3. User creates account or signs in
   - `components/onboarding/AccountStep.tsx`

4. User imports data
   - CV upload via `/api/parse-cv`
   - broader import via `/api/import` for file/text/GitHub when enabled
   - `app/api/parse-cv/route.ts`
   - `app/api/import/route.ts`

5. User reviews and edits imported data
   - `components/onboarding/ReviewStep.tsx`

6. User chooses slug/address
   - checked by `/api/check-slug`
   - profile row created by `/api/account/profile`
   - slug can be changed before publishing via `/api/account/slug`
   - `app/api/check-slug/route.ts`
   - `app/api/account/profile/route.ts`
   - `app/api/account/slug/route.ts`

7. User triggers AI generation
   - `app/api/generate/route.ts`

8. User previews portfolio
   - `app/preview/[portfolioId]/page.tsx`

9. User opens payment modal and chooses Basic or Pro
   - `components/UpgradeModal.tsx`

10. Checkout starts through Paystack
   - `app/api/checkout/route.ts`

11. Payment is verified on return and/or webhook
   - `app/checkout/return/ReturnClient.tsx`
   - `app/api/checkout/verify/route.ts`
   - `app/api/paystack-webhook/route.ts`

12. Portfolio becomes public
   - rendered at `/{slug}` on main domain or `slug.liveportfolio.site`
   - `middleware.ts`
   - `app/portfolio/[slug]/page.tsx`

13. User manages portfolio in dashboard
   - `app/dashboard/page.tsx`

### Difference between Free, Basic, and Pro

From the source of truth in `lib/plans.ts`:

#### Free
Includes:
- build, edit, and preview privately
- switch between 3 templates
- preview every template with own details

Does **not** include:
- publishing
- Pro templates
- analytics
- QR code
- weekly AI score

#### Basic
Includes everything in Free, plus:
- publish at own LivePortfolio address

#### Pro
Includes everything in Basic, plus:
- 7 additional role-specific templates
- visitor analytics
- QR code
- weekly AI career score

#### Explicitly planned but not built
Marked `status: 'soon'` in `lib/plans.ts`:
- AI assistant
- MCP integration
- GitHub sync
